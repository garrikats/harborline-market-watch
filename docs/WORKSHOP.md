# Workshop flow

1. Plan: Bob analyzes this repository and proposes an implementation plan.
2. Scaffold: Bob builds the React app sub-task by sub-task.
3. Validate: lint, test and build must all pass locally.
4. Publish: push to GitHub; CI runs on feature branches and pull requests.
5. Evolve: Bob implements a GitHub issue on its own branch and prepares a merge-ready PR.
